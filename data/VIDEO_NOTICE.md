# Example indoor footage

`source_indoor_walking.mp4` was supplied as example footage for the demonstration.
Its original provenance / redistribution rights were not established in this project.

**Before posting this repository publicly, verify you have permission to
redistribute this source clip and the derived GIF/MP4 examples.** If you do not,
replace the example clip with footage you own or a properly licensed substitute,
then regenerate the demo media using `run_demo.py`.

The MIT license at the repository root applies to the **code written for this
project**, not automatically to third-party footage or other media.
